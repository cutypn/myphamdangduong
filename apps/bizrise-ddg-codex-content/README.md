# Bizrise DDG Codex Content Exports

Source-of-truth runtime packages generated by `CODEX-WEB-CONTENT-HTML` after G4 + SEO + G7 PASS.

Expected paths:

- `exports/products/*.json`
- `exports/articles/*.json`

WordPress runtime does not generate production copy. It imports only schema `1.0` packages with `status=APPROVED` and QA gates `g4=PASS`, `seo=PASS`, `g7=PASS`, `html=PASS`.

Product media roles:
- `PRODUCT_PACKSHOT`: Featured/card/modal/desktop/mobile.
- `PRODUCT_GALLERY` / `PACKAGING`: product detail gallery.
- `LEGAL_DOCUMENT`: detail-page documents only; never Featured Image.
